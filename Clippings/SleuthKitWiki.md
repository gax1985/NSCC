Welcome to the **SleuthKitWiki**. This wiki is for sharing knowledge about projects associated with [sleuthkit.org](http://www.sleuthkit.org/). If you use any of these tools, feel free to add or improve content on this site. If you want to contribute to this site and are looking for a place to start, [Special:WantedPages](https://wiki.sleuthkit.org/index.php?title=Special:WantedPages "Special:WantedPages") contains a list of pages that need to be started.

This site is organized based on the different projects:

- [The Sleuth Kit](https://wiki.sleuthkit.org/index.php?title=The_Sleuth_Kit "The Sleuth Kit"): A library and set of command line tools to analyze disk images.
- [Autopsy](https://wiki.sleuthkit.org/index.php?title=Autopsy "Autopsy"): A graphical interface to the Sleuth Kit and other digital forensics tools.
- [mac-robber](https://wiki.sleuthkit.org/index.php?title=Mac-robber "Mac-robber"): A simple tool to grab time data from a live system for making timelines.
